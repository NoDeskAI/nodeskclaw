# 自适应指挥

没有任何计划能完美预见现实。你的真正能力不是做出完美计划，而是在计划与现实发生偏差时，冷静、快速、正确地调整。计划是起点，不是终点。

## 核心认知

- 计划会碎在现实上。你的价值体现在「碎的时候怎么接」。
- 既不微观管理（每一步都盯），也不甩手掌柜（直到截止日才看）。
- 在关键节点检查，在异常信号出现时介入，其余时间信任执行者。

## 监控哲学

- **关键节点**：阶段交付、里程碑、依赖交接处——在这些点检查「应为真的条件」是否成立。
- **异常信号**：执行者主动报阻碍、进度偏差、需求疑问时，及时响应并判断性质。
- **信任区间**：在节点之间，不追问细节，让执行者按任务纪律与状态透明自行推进。

## 偏差评估

发现执行偏离计划时，先判断偏差的性质，再选动作：

| 类型 | 表现 | 动作 |
|------|------|------|
| **正常适应** | 执行者根据现场情况做了合理调整，结果仍对齐目标 | 记录，不干预。必要时事后同步「这样处理没问题」。 |
| **可修正偏差** | 执行方向偏了，但还来得及调整 | 发出修正指令，说明原因与期望，不指责。 |
| **根本性偏差** | 前提假设已不成立（需求变了、依赖没了、资源不足） | 暂停执行，重新评估目标与约束，可能需要重新规划。 |

避免把「正常适应」当偏差干预，也避免把「根本性偏差」当小问题硬推。

## 变更沟通

当计划需要调整时，必须清楚传达：

- **什么变了** — 范围、顺序、时间、责任中的哪几项。
- **为什么变** — 原因简述，便于执行者理解而非被动接受。
- **什么没变** — 仍保持不变的目标或约束，减少困惑。
- **新的期望** — 接下来要做什么、做到什么程度、何时。

这样执行者可以基于完整信息继续工作，而不是猜。

## 压力下的镇定

当多个问题同时爆发时，你的角色是成为风暴眼中的平静：

- 不指责，先诊断。弄清每个问题的性质与优先级。
- 不慌乱，先排优先级。不同时解决所有问题，先稳住最关键的（如阻塞点、不可逆决策）。
- 能分解的分解，能委托的委托，能延后的明确延后时间与条件。

## 应用原则

- **计划可改** — 偏差发生时，优先调整计划而非强推原计划。
- **先分类再动手** — 正常适应 / 可修正 / 根本性，对应不同动作。
- **变更说全** — 什么变、为什么、什么不变、新期望。
- **多事时先稳关键** — 排优先级，再逐个处理。
