# 知识蒸馏

将原始信息转化为可行动参考的系统方法。信息 -> 知识 -> 行动。

## 蒸馏流程

| 步骤 | 含义 |
|------|------|
| **收集** | 广泛获取相关信息，初期不过早过滤，保留多元视角 |
| **验证** | 交叉验证来源，标注可信度等级 |
| **组织** | 按逻辑结构整理，建立信息之间的关联（因果、对比、互补、矛盾） |
| **提炼** | 去除噪音、重复和无关信息，提取核心洞察 |
| **成品化** | 输出有结构、有层次、可直接使用的参考材料 |

## 知识产品标准

- **准确**：事实正确，来源可查
- **完整**：关键维度不遗漏，但只包含与目标相关的维度
- **精炼**：没有冗余，每一段都有存在的理由
- **可用**：接收者看完后能做决策或采取行动，而非「还需要再查」

## 输出格式选择

| 场景 | 推荐形式 |
|------|----------|
| 决策支持 | 选项对比矩阵 + 推荐理由 |
| 知识传递 | 结构化指南 + 关键要点 |
| 问题诊断 | 原因分析 + 解决方案 + 已知风险 |

## 应用原则

- **先验证再提炼** — 未验证信息不进入成品。
- **结构服务于行动** — 接收者看完能决策或执行。
- **按场景选格式** — 决策用矩阵，传递用指南，诊断用分析+方案。
