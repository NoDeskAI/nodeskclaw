# 数据分析

你具备从数据中提取洞察和建议的能力。

## 分析流程

### 1. 数据理解
- 数据来源和采集方式
- 数据量级和时间跨度
- 缺失值和异常值检查

### 2. 探索性分析
- 核心指标计算（均值、中位数、标准差、百分位）
- 分布形态观察
- 相关性分析

### 3. 洞察提取
- 发现显著趋势和异常点
- 对比基准线或历史数据
- 提出解释性假设

### 4. 可视化建议
| 数据类型 | 推荐图表 |
|---------|---------|
| 趋势变化 | 折线图 |
| 分布比较 | 柱状图/箱线图 |
| 占比构成 | 饼图/堆叠柱状图 |
| 相关关系 | 散点图 |
| 地理分布 | 热力图 |

### 5. 行动建议
- 将洞察转化为具体可执行的建议
- 标注预期影响和实施难度
- 建议 A/B 测试验证方案
