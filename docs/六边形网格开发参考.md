# 六边形网格开发参考

基于 [Red Blob Games - Hexagonal Grids](https://www.redblobgames.com/grids/hexagons/) 及其 [Implementation Guide](https://www.redblobgames.com/grids/hexagons/implementation.html) 整理。原文由 Amit Patel 维护超过 25 年，是 hex grid 游戏开发领域最权威的参考资料。

---

## 1. 几何基础

六边形有两种朝向：**Pointy-top**（尖顶朝上）和 **Flat-top**（平顶朝上）。

### 尺寸关系

设 `size` 为中心到顶点的距离（外接圆半径）：

| 属性 | Pointy-top | Flat-top |
|------|-----------|----------|
| 宽度 width | `sqrt(3) * size` | `2 * size` |
| 高度 height | `2 * size` | `sqrt(3) * size` |
| 水平间距 horiz | `sqrt(3) * size` | `3/2 * size` |
| 垂直间距 vert | `3/2 * size` | `sqrt(3) * size` |

### 顶点角度

Pointy-top 的第一个顶点起始角度为 **30 度**（即 `start_angle = 0.5`，表示 0.5 * 60 度）。

Flat-top 的第一个顶点起始角度为 **0 度**（即 `start_angle = 0.0`）。

第 i 个顶点的角度：

```
angle_deg = 60 * i + start_angle * 60
angle_rad = PI / 180 * angle_deg
corner_x = center_x + size * cos(angle_rad)
corner_y = center_y + size * sin(angle_rad)
```

> **本项目**：使用 Pointy-top，`useHexLayout.ts` 的 `hexVertices()` 从 -30 度开始（等价于 `60 * i - 30`）。

## 2. 坐标系统

### 2.1 Offset 坐标

最常见的方案——偶数/奇数行/列偏移。直观但**不支持向量运算**（加减法在不同行/列上行为不同），算法编写困难。

四种变体：`even-r`、`odd-r`（pointy-top）、`even-q`、`odd-q`（flat-top）。

### 2.2 Cube 坐标（立方体坐标）

核心洞察：hex 网格可以看作 3D 立方体网格在对角面 `q + r + s = 0` 上的切片。

三个轴 `q, r, s` 之间始终满足约束：**q + r + s = 0**。

优势：
- 支持标准向量运算（加、减、缩放）
- 距离、旋转、反射、画线等算法都很简洁
- 具有六边形对称性

### 2.3 Axial 坐标（轴向坐标）

**与 Cube 坐标本质相同**，只是不存储 `s`。需要时通过 `s = -q - r` 计算。

存储为 `(q, r)`，算法需要 `s` 时临时计算。

### 2.4 Doubled 坐标

将水平或垂直步长加倍。约束：`(col + row) % 2 == 0`。

比 Offset 更容易处理（邻居向量不依赖奇偶行），但不如 Axial/Cube 优雅。

### 坐标系推荐

| 特性 | Offset | Doubled | Axial | Cube |
|------|--------|---------|-------|------|
| 向量运算（加减缩放） | 不支持 | 支持 | 支持 | 支持 |
| 矩形地图存储 | 天然适配 | 需适配 | 需适配 | 需适配 |
| 任意形状存储（hash） | 支持 | 支持 | 支持 | 支持 |
| 六边形对称性 | 无 | 无 | 无 | 有 |
| 算法简洁度 | 差 | 中等 | 好 | 好 |

**推荐**：存储用 Axial `(q, r)`，算法中需要时计算 `s = -q - r` 当作 Cube 使用。

> **本项目**：使用 Axial 坐标 `(q, r)`，定义在 `useHexLayout.ts` 的 `HexCoord` 接口。

## 3. 坐标转换

### Axial <-> Cube

```
// Axial -> Cube
cube = Cube(q, r, -q - r)

// Cube -> Axial
axial = Hex(q, r)   // 直接丢弃 s
```

### Axial <-> Offset（odd-r 为例）

```
// Axial -> odd-r Offset
col = q + (r - (r & 1)) / 2
row = r

// odd-r Offset -> Axial
q = col - (row - (row & 1)) / 2
r = row
```

注意：`r & 1` 用于判断奇偶，避免取模运算对负数的歧义。

> **本项目**：暂未实现 Offset/Doubled 坐标转换，仅使用 Axial。

## 4. 邻居计算

### Cube / Axial 邻居

六个方向的偏移量：

```
hex_directions = [
    Hex(+1,  0, -1), Hex(+1, -1,  0), Hex( 0, -1, +1),
    Hex(-1,  0, +1), Hex(-1, +1,  0), Hex( 0, +1, -1)
]

function hex_neighbor(hex, direction):
    return hex_add(hex, hex_directions[direction])
```

用 Axial 表示（省略 `s`）：

```
axial_directions = [
    Hex(+1, 0), Hex(+1, -1), Hex(0, -1),
    Hex(-1, 0), Hex(-1, +1), Hex(0, +1)
]
```

### 对角邻居

六个对角方向（跳过一个 hex 的距离）：

```
diag_directions = [
    Hex(+2, -1, -1), Hex(+1, -2, +1), Hex(-1, -1, +2),
    Hex(-2, +1, +1), Hex(-1, +2, -1), Hex(+1, +1, -2)
]
```

> **本项目**：`Workspace2D.vue` 的走廊臂方向检测使用了 6 方向邻居判断（通过遍历 hex 偏移量）。无独立的 `hex_neighbor` 函数。

## 5. 距离计算

### Cube 距离

hex 距离 = Cube 曼哈顿距离的一半：

```
function cube_distance(a, b):
    return (abs(a.q - b.q) + abs(a.r - b.r) + abs(a.s - b.s)) / 2

// 等价形式
function cube_distance(a, b):
    return max(abs(a.q - b.q), abs(a.r - b.r), abs(a.s - b.s))
```

### Axial 距离

内联 Cube 距离后：

```
function axial_distance(a, b):
    var dq = abs(a.q - b.q)
    var dr = abs(a.r - b.r)
    return (dq + abs(dq + a.r - b.r - dq) + dr) / 2
    // 简化：(abs(a.q - b.q) + abs(a.q + a.r - b.q - b.r) + abs(a.r - b.r)) / 2
```

### 欧几里得距离（Axial）

```
euclidean = sqrt(dq*dq + dr*dr + dq*dr)
```

> **本项目**：暂未实现 hex 距离函数。`useTopologyBFS.ts` 使用 BFS 进行拓扑距离计算。

## 6. 线段绘制

在两个 hex 之间画线：对浮点坐标做线性插值，然后取整到最近 hex。

```
function hex_lerp(a, b, t):
    return FractionalHex(
        lerp(a.q, b.q, t),
        lerp(a.r, b.r, t),
        lerp(a.s, b.s, t))

function hex_linedraw(a, b):
    N = hex_distance(a, b)
    results = []
    step = 1.0 / max(N, 1)
    for i in 0..N:
        results.append(hex_round(hex_lerp(a, b, step * i)))
    return results
```

**边界处理**：当插值落在 hex 边界上时，`hex_round` 可能不一致。解决方案是给起点加一个微小偏移（nudge）：

```
a_nudge = FractionalHex(a.q + 1e-6, a.r + 1e-6, a.s - 2e-6)
```

> **本项目**：`useFlowAnimation.ts` 的 `getParticlePosition()` 使用了线性插值（lerp）沿路径移动粒子，但是在像素空间而非 hex 空间做 lerp。暂无 hex 空间的 linedraw 实现。

## 7. 移动范围

### 坐标范围查询

给定中心和范围 N，找出 N 步内所有 hex：

```
function hex_range(center, N):
    results = []
    for q in -N..+N:
        for r in max(-N, -q-N)..min(+N, -q+N):
            results.append(hex_add(center, Hex(q, r)))
    return results
```

hex 数量公式：`1 + 3 * N * (N + 1)`

### 范围交集

两个六边形区域的交集 = 分别对 q, r, s 范围取交集：

```
qmin = max(H1.q - N1, H2.q - N2)
qmax = min(H1.q + N1, H2.q + N2)
// 对 r, s 同理，然后用上面的嵌套循环生成 hex 列表
```

### 带障碍物的范围（BFS 洪水填充）

```
function hex_reachable(start, movement):
    visited = set(start)
    fringes = [[start]]
    for k in 1..movement:
        fringes.append([])
        for hex in fringes[k-1]:
            for dir in 0..5:
                neighbor = hex_neighbor(hex, dir)
                if neighbor not in visited and not blocked(neighbor):
                    visited.add(neighbor)
                    fringes[k].append(neighbor)
    return visited
```

> **本项目**：`useTopologyBFS.ts` 的 `findReachableEndpoints()` 实现了基于拓扑图的 BFS 可达搜索（非标准 hex 邻居，而是通过拓扑边连接）。

## 8. 旋转与反射

### 旋转

Cube 坐标下，60 度旋转通过坐标位移和取反实现：

```
// 顺时针 60 度（右旋）
rotate_right(q, r, s) = (-r, -s, -q)

// 逆时针 60 度（左旋）
rotate_left(q, r, s) = (-s, -q, -r)
```

绕任意中心 `center` 旋转位置 `hex`：

1. `vec = hex - center`（向量减法）
2. `rotated_vec = rotate(vec)`
3. `result = rotated_vec + center`

120 度旋转 = 连续两次 60 度旋转。180 度旋转 = 三次。

### 反射

沿某条轴反射 = 交换另外两个坐标：

```
reflectQ(h) = Cube(h.q, h.s, h.r)   // 沿 q 轴反射
reflectR(h) = Cube(h.s, h.r, h.q)   // 沿 r 轴反射
reflectS(h) = Cube(h.r, h.q, h.s)   // 沿 s 轴反射
```

另外三个反射方向 = 取反 + 上述反射。

## 9. 环与螺旋

### 单环

半径为 `radius` 的环上的所有 hex：

```
function cube_ring(center, radius):
    results = []
    hex = center + cube_direction(4) * radius   // 起点：某个角落
    for i in 0..5:
        for j in 0..radius-1:
            results.append(hex)
            hex = hex_neighbor(hex, i)
    return results
```

环的周长 = `6 * radius`。

### 螺旋遍历

从中心向外一圈圈遍历：

```
function cube_spiral(center, radius):
    results = [center]
    for k in 1..radius:
        results.extend(cube_ring(center, k))
    return results
```

### Hex 计数

N 环内（含中心）的 hex 总数：**1 + 3 * N * (N + 1)**

> **本项目**：`useHexLayout.ts` 的 `spiralLayout()` 实现了螺旋布局，用于自动分配 Agent 位置。起点从 `(1, 0)` 开始，使用六方向步进沿环遍历。

## 10. 视野计算（Field of View）

### 简单射线法

对范围内每个 hex 画一条线（用 `hex_linedraw`），如果线上没有碰到障碍物，则该 hex 可见。

```
function field_of_view(center, range):
    visible = set()
    for hex in hex_range(center, range):
        line = hex_linedraw(center, hex)
        blocked = false
        for step in line:
            if is_wall(step):
                blocked = true
                break
        if not blocked:
            visible.add(hex)
    return visible
```

缺点：大范围下较慢。

### 阴影投射法（Shadow Casting）

从中心向外螺旋扩展，维护一组"被遮挡的角度范围"。遇到障碍物时将其角度范围加入阴影集合。如果一个 hex 完全在阴影范围内，则不可见。

适合对性能有要求的场景，但实现复杂度明显更高。

> **本项目**：暂未实现视野计算。

## 11. Hex-to-Pixel / Pixel-to-Hex

### Hex -> Pixel（Axial 坐标）

**Pointy-top：**

```
x = size * (sqrt(3) * q + sqrt(3)/2 * r)
y = size * (3/2 * r)
```

**Flat-top：**

```
x = size * (3/2 * q)
y = size * (sqrt(3)/2 * q + sqrt(3) * r)
```

### Layout 矩阵表示

正向矩阵（hex -> pixel）和逆矩阵（pixel -> hex）：

**Pointy-top：**

```
forward:  f0=sqrt(3), f1=sqrt(3)/2, f2=0,        f3=3/2
inverse:  b0=sqrt(3)/3, b1=-1/3,    b2=0,        b3=2/3
start_angle = 0.5   // 即 30 度
```

**Flat-top：**

```
forward:  f0=3/2,     f1=0,        f2=sqrt(3)/2, f3=sqrt(3)
inverse:  b0=2/3,     b1=0,        b2=-1/3,      b3=sqrt(3)/3
start_angle = 0.0    // 即 0 度
```

通用转换（支持非均匀缩放和原点偏移）：

```
function hex_to_pixel(layout, h):
    x = (M.f0 * h.q + M.f1 * h.r) * layout.size.x
    y = (M.f2 * h.q + M.f3 * h.r) * layout.size.y
    return Point(x + layout.origin.x, y + layout.origin.y)
```

### Pixel -> Hex

逆运算：先减原点、除缩放、再乘逆矩阵。结果是浮点 hex 坐标，需要 `hex_round` 取整。

```
function pixel_to_hex(layout, p):
    pt = Point((p.x - layout.origin.x) / layout.size.x,
               (p.y - layout.origin.y) / layout.size.y)
    q = M.b0 * pt.x + M.b1 * pt.y
    r = M.b2 * pt.x + M.b3 * pt.y
    return hex_round(FractionalHex(q, r, -q-r))
```

### 非均匀缩放（适配 Sprite）

- Pointy-top sprite `W x H`：`size = Point(W / sqrt(3), H / 2)`
- Flat-top sprite `W x H`：`size = Point(W / 2, H / sqrt(3))`

### Y 轴翻转

将 `size.y` 设为负值可翻转 `r` 轴方向（适配 y 轴朝上的 3D 库）。

> **本项目**：`useHexLayout.ts` 的 `axialToWorld()` 实现了 Pointy-top 的 hex-to-pixel 转换，`HEX_SIZE = 1.2` 为均匀缩放，无原点偏移。`Workspace2D.vue` 额外乘以 `SCALE = 60` 转为 SVG 像素。暂未实现 pixel-to-hex 反向转换。

## 12. 坐标取整（Rounding）

将浮点 hex 坐标取整到最近的整数 hex。用于 pixel-to-hex 和 linedraw。

```
function cube_round(frac):
    q = round(frac.q)
    r = round(frac.r)
    s = round(frac.s)

    q_diff = abs(q - frac.q)
    r_diff = abs(r - frac.r)
    s_diff = abs(s - frac.s)

    if q_diff > r_diff and q_diff > s_diff:
        q = -r - s
    else if r_diff > s_diff:
        r = -q - s
    else:
        s = -q - r

    return Cube(q, r, s)
```

原理：分别对 q, r, s 取整后可能破坏 `q + r + s = 0` 约束。修正方法：找到偏差最大的分量，用约束重新计算它。

Axial 取整：先转 Cube，取整，再转回 Axial。

> **本项目**：暂未实现 `cube_round`。如需实现 pixel-to-hex（如鼠标点击定位 hex），这是必要的前置算法。

## 13. 地图存储

### Hash Table（推荐）

最灵活，支持任意形状（含空洞）：

```
// TypeScript / JavaScript
const map = new Map<string, TileData>()
map.set(`${q},${r}`, data)
```

### 2D 数组

紧凑存储，适合固定形状的大地图。访问方式取决于地图形状：

| 地图形状 | 存储公式（Pointy-top） |
|---------|----------------------|
| 矩形 | `array[r][q + floor(r/2)]`（等价于 odd-r offset） |
| 六边形 | `array[r][q - max(0, N-r)]`，行大小 `2*N+1 - abs(N-r)` |
| 菱形 | `array[r][q]` |
| 三角形（下） | `array[r][q]`，行大小 `N+1-r` |
| 三角形（上） | `array[r][q - N+1+r]`，行大小 `1+r` |

### 各形状地图的生成循环

六边形地图（最常用）：

```
for q in -N..+N:
    r1 = max(-N, -q - N)
    r2 = min(+N, -q + N)
    for r in r1..r2:
        map.insert(Hex(q, r))
```

矩形地图（Pointy-top）：

```
for r in top..bottom:
    r_offset = floor(r / 2)
    for q in (left - r_offset)..(right - r_offset):
        map.insert(Hex(q, r))
```

> **本项目**：`Workspace2D.vue` 使用 `GRID_RANGE = 8` 的六边形区域生成网格（`|q| + |r| + |s| <= GRID_RANGE * 2`），Agent/走廊/Human 等实体存储在后端数据库，前端通过 Pinia store 管理。

## 15. 寻路（Pathfinding）

Hex 网格上的寻路与方格网格完全相同，只需替换两个接口：

1. **neighbors**：使用 hex 6 方向邻居函数（过滤不可通行的 hex）
2. **heuristic**：使用 hex 距离公式（`cube_distance` 或 `axial_distance`），乘以移动代价

A*、Dijkstra、BFS 等标准图算法均可直接使用。

```
// A* 启发函数示例
function heuristic(a, b):
    return hex_distance(a, b) * MOVE_COST

// 邻居函数
function get_neighbors(hex):
    result = []
    for dir in 0..5:
        n = hex_neighbor(hex, dir)
        if is_passable(n):
            result.append(n)
    return result
```

更多寻路算法细节参见：[Red Blob Games - Introduction to A*](https://www.redblobgames.com/pathfinding/a-star/introduction.html)

> **本项目**：`useTopologyBFS.ts` 实现了 BFS 寻路（`findPath()`）和可达搜索（`findReachableEndpoints()`）。寻路基于拓扑边而非标准 hex 邻居，只经过 corridor/blackboard 类型节点。
