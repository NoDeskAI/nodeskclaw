# NoDeskClaw - 页面总览与线框图

> 与 PRD v0.4 配套，共 **11 个页面 + 6 个弹窗**

---

## 页面地图（Sitemap）

```
NoDeskClaw
│
├── 🔐 登录页                          /login
│
├── 🏠 Dashboard（总览）                /
│
├── 📦 实例管理
│   ├── 实例列表                        /instances
│   ├── 实例详情                        /instances/:id
│   ├── 实例基因                        /instances/:id/genes
│   └── 模型配置（LLM 配置）            /instances/:id/settings
│
├── 🚀 一键部署（分步表单）              /deploy
│
├── 📋 日志查看                         /instances/:id/logs
│
├── 📊 监控
│   ├── Pod 监控                        /instances/:id/monitor
│   ├── 部署历史                        /instances/:id/history
│   └── 事件查看                        /events
│
├── ⚙️ 集群管理
│   ├── 集群概览                        /cluster
│   └── 集群接入（添加/编辑）            /cluster/setup
│
├── 🎯 赛博办公室（Portal）
│   ├── 办公室画布                      /workspace/:id
│   └── 添加 Agent                     /workspace/:id/add-agent
│
├── 基因市场（含进化趋势 Tab）            /gene-market
│
└── 🔧 设置                            /settings
    ├── 个人设置
    └── 系统设置 (M3)

弹窗 / 抽屉：
  ├── 删除确认弹窗
  ├── 扩缩容弹窗
  ├── 重启确认弹窗
  ├── 滚动更新弹窗
  ├── 部署预检弹窗
  ├── KubeConfig 导入弹窗
  ├── ChatPanel（群聊侧边栏，右侧分屏可拖拽宽度 19.1%~61.8% 屏幕宽度、localStorage 持久化，含 Tiptap 富文本编辑器（@ 提及 / 命令 Tag 内嵌、hover Popover、原子删除、needsAgent 链式选择合并 Tag）、45s typing 超时兜底、常驻滚动条 + 内容驱动高度、命令下拉标记"立即执行/Tag"、底部 @// 按钮 + 发送按钮、/status 等系统消息持久化、Agent 名称/slug 省略+hover 复制、Agent 消息 Markdown 渲染（marked）、Agent 气泡 92% 宽度、聚焦模式：保留顶栏，主区域变为黑板+聊天双栏）
  ├── BlackboardOverlay（黑板编辑覆盖层，支持弹层模式和嵌入模式）
  └── HexActionDrawer（工位操作抽屉，底部滑入，按 Hex 类型切换内容，定位基于聊天侧栏实际宽度动态偏移）
```

## P16 实例基因 Tab `/instances/:id/genes`

数据源：`GET /instances/:id/skills`（Pod 扫描驱动），列表展示实例 Pod 内的所有实际 skills，分为两种类型：

### Hub 基因卡片

- 来源于基因 Hub 的 skill（slug 可在 Hub 中找到匹配）
- 展示：名称、slug、版本、标签、状态徽标、效能进度条、使用次数
- 操作按钮：发布变体、恢复学习（简化状态）、遗忘
- 支持 `focus_gene_id` 查询参数：命中时将对应基因置顶

### 涌现基因卡片

- 来源于 Meta Learning 或其他机制涌现的 skill（Hub 中找不到匹配）
- 展示：名称、skill_name、截断描述、文件数量、"基因涌现"紫色徽标
- 如 FrontMatter 中 `always: true` 则显示"常驻激活"标签
- 点击卡片打开详情 Dialog，展示完整 SKILL.md 内容（Markdown 渲染）

### 学习基因 Dialog（内嵌基因市场）

点击"学习基因"按钮打开全屏 Dialog（不跳转页面），学习操作自动绑定当前实例：

- Tab 切换：基因 / 基因组
- 搜索栏 + 标签筛选 + 分类筛选 + 排序（与 P13 基因市场一致）
- 卡片网格展示，已学习基因显示"已学习"角标（绿色勾）
- 点击卡片进入 Dialog 内详情视图（含描述、基因内容、工具能力、评分）
- 详情视图"学习到当前实例"按钮直接调用安装 API，无需再选实例
- 基因组详情视图展示包含基因列表（Tab 切换查看各基因内容），一键批量学习
- 安装成功后关闭 Dialog 并刷新已安装列表

### 过渡状态自动轮询

当存在处于 `learning`/`installing`/`forgetting`/`uninstalling` 状态的基因时，页面每 8 秒自动刷新列表（Pod 扫描比纯 DB 查询稍慢），所有基因进入稳定状态后停止轮询。轮询时静默更新数据，不触发全屏 loading。

### Pod 不可用降级

当实例 Pod 未运行或 kubectl exec 失败时，页面显示"实例不可用，无法加载基因列表"错误提示，不回退到 DB 数据。

- 语言切换交互：当前语言项高亮、点击外部关闭、`Esc` 关闭、`Enter` 选择
- P14/P15 页面约定：基因详情页与基因组详情页的用户可见固定文案（标题、按钮、评分标签、弹窗与空态）全部走 i18n 词条
- 办公室/实例/成员页面约定：办公室列表页、实例列表页、成员管理页的标题、按钮、状态、表头、搜索占位符、计数文案全部走 i18n 词条

- 管理端总览页面约定：Dashboard 统计卡片、快捷操作、最近实例、实时动态标题与底栏连接状态（含 SSE 状态）全部走 i18n 词条
- 管理端实例列表页约定：`/instances` 页标题、搜索占位、状态/命名空间筛选项、卡片“详情”按钮、副本文案与表格列头全部走 i18n 词条
- 管理端事件中心页约定：`/events` 页标题、连接状态、重连按钮、筛选标签（实例/类型/全部）、事件计数与“实时事件流”标题全部走 i18n 词条
- 管理端总览页面异常态约定：首屏并发请求任一失败时，页面必须退出 loading（加载中）态并展示错误提示 + 重试按钮，不允许卡死在“加载中”
- 管理端应用壳异常态约定：刷新后 App 初始化失败时，主内容区显示统一错误态与“重试初始化”入口，不允许只显示空白或无反馈
- 管理端连接策略约定：全局 SSE 与 token 健康轮询在“初始化完成 + 当前集群有效”后才启动，断连采用退避重试并限制上限
- 漏项审计采用统一口径（仅统计用户可见文案），基线清单见 `docs/前端i18n漏项审计清单.md`

## 赛博办公室过道可视化

### 3D 视图新增元素

- **过道 Hex**：半透明六棱柱中继节点，显示名称标签（如"产品通道"），区别于 AI 员工实心六边形
- **Human Hex**：更细更高的暖色六棱柱（默认琥珀色 #f59e0b，可自定义），发光边缘始终亮起，顶部显示工位名称（display_name，创建时默认取成员用户名）
- **连接线**：发光管道/光线，有向连接显示箭头动画（粒子流向），双向连接无箭头
- Hex 类型扩展为 5 种：empty / agent / blackboard / human / corridor

### 2D 视图新增元素

- 过道 Hex：虚线边框六边形 + 名称
- Human Hex：实心六边形，暖色填充 + 人形图标
- 连接线：SVG 线段 + 箭头标记方向

### 交互操作

- 空白格子右键/长按 → 弹出菜单增加"放置过道""放置人类工位"选项
- 放置人类工位时：选择办公室成员 → 自动以成员用户名作为工位默认名称
- 选中两个相邻 Hex → "创建直连"选项，可选方向
- 选中已有连接 → 修改方向（both/a_to_b/b_to_a）/ 删除
- 选中 Human Hex → 重命名工位、修改颜色、移动、移除工位
- 选中过道 Hex → 重命名、移动、删除（级联删除自动连接）、查看经过的消息数
- 选中 AI 员工 Hex → 打开对话、查看详情（弹窗）、移动、从办公室移除

### 移动 Hex 交互

- 通过 HexActionDrawer 中「移动」按钮进入移动模式（AI 员工 / 过道 / Human 均支持）
- 移动模式下：画布顶部显示琥珀色提示条（含取消按钮），源 Hex 脉冲高亮，空格以绿色虚线边框高亮为可选目标
- 点击空格 → 执行移动（调用后端 API 更新位置，过道 Hex 自动级联更新连接关系）
- Escape 或点击取消按钮 → 退出移动模式

### 键盘操作

- 方向键 / WASD → 始终平移画布
- `+` / `-` → 缩放
- `0` → 重置视角
- `Esc` → 移动模式下退出移动模式，否则取消选中

## 黑板 v2 面板

点击中心黑板 Hex 打开多 Tab 面板（替代原有纯文本编辑器）：

### 目标 Tab

- OKR 卡片列表，每个目标含标题和 Key Results 进度条
- 支持添加/编辑/删除目标
- 进度可由 AI 员工通过 Self-MCP 自动更新

### 任务 Tab

- 看板视图：Todo / Doing / Done / Blocked 四列
- 每个任务卡片显示：标题、指派人（AI 员工或 Human 头像）、优先级色块、截止日期
- 支持拖拽切换状态
- AI 员工通过 Self-MCP 创建/更新任务

### 状态 Tab

- 成员列表（AI 员工 + Human），每行显示：头像/图标、名称、当前状态（运行中/空闲/思考中/离线）、正在处理的任务
- 状态由系统自动维护

### 绩效 Tab

- 每个 AI 员工的综合绩效分
- 趋势图（周/月维度折线图）
- 对比视图（团队内排名柱状图）

### 笔记 Tab

- 保留原有 manual_notes 文本编辑器

### 拓扑监控 Tab

- 消息流量热力图：2D/3D 视图中以独立覆盖层绘制端点间直连线，线宽和透明度由消息计数映射（1px~5px, opacity 0.15~0.6），数据来自 `GET /workspaces/{id}/topology/message-flow`
- 拓扑消息流动画：SSE `agent:collaboration` 事件触发 BFS 寻路 + 粒子/小球动画（2D SVG circle / 3D SphereGeometry），700ms 沿路径 lerp，到达后目标 hex 脉冲
- AI 员工协作对话面板：HexActionDrawer 快捷键 L，右侧滑出 400px 面板，展示单个 AI 员工的协作消息时间线
- Chat Sidebar 双 Tab：Tab 1 "中央黑板"（原群聊），Tab 2 "协作流"（全局协作时间线 CollaborationTimeline），支持按 AI 员工过滤、点击条目回放路径动画
- 孤岛检测：未连接的 AI 员工标记为"隔离"
- 可达性矩阵：从任意节点出发的可达范围
