# ClawBuddy - 页面总览与线框图

> 与 PRD v0.4 配套，共 **11 个页面 + 6 个弹窗**

---

## 页面地图（Sitemap）

```
ClawBuddy
│
├── 🔐 登录页                          /login
│
├── 🏠 Dashboard（总览）                /
│
├── 📦 实例管理
│   ├── 实例列表                        /instances
│   ├── 实例详情                        /instances/:id
│   ├── 实例基因                        /instances/:id/genes
│   └── 实例设置（LLM 配置）            /instances/:id/settings
│
├── 🚀 一键部署（分步表单）              /deploy
│
├── 📋 日志查看                         /instances/:id/logs
│
├── 📊 监控
│   ├── Pod 监控                        /instances/:id/monitor
│   ├── 部署历史                        /instances/:id/history
│   └── 事件查看                        /events
│
├── ⚙️ 集群管理
│   ├── 集群概览                        /cluster
│   └── 集群接入（添加/编辑）            /cluster/setup
│
├── 🎯 工作区（Portal）
│   ├── 工作区画布                      /workspace/:id
│   └── 添加 Agent                     /workspace/:id/add-agent
│
├── 基因市场（含进化趋势 Tab）            /gene-market
│
└── 🔧 设置                            /settings
    ├── 个人设置
    └── 系统设置 (M3)

弹窗 / 抽屉：
  ├── 删除确认弹窗
  ├── 扩缩容弹窗
  ├── 重启确认弹窗
  ├── 滚动更新弹窗
  ├── 部署预检弹窗
  ├── KubeConfig 导入弹窗
  ├── ChatPanel（群聊侧边栏，右侧分屏 400px，含 Tiptap 富文本编辑器（@ 提及 / 命令 Tag 内嵌、hover Popover、原子删除、needsAgent 链式选择合并 Tag）、45s typing 超时兜底、常驻滚动条 + 内容驱动高度、命令下拉标记"立即执行/Tag"、底部 @// 按钮 + 发送按钮、/status 等系统消息持久化、Agent 名称/slug 省略+hover 复制、Agent 消息 Markdown 渲染（marked）、Agent 气泡 92% 宽度）
  ├── BlackboardOverlay（黑板编辑覆盖层）
  └── HexActionDrawer（工位操作抽屉，底部滑入，按 Hex 类型切换内容）
```

**交互说明**：

- 每个 Provider 卡片内嵌 Key 来源 radio（组织 Key / 个人 Key），两个选项始终可见
- 组织 Key：选中后显示"通过组织代理调用，无需输入 Key"，请求经 llm_proxy 自动路由到管理员配置的组织 Key
- 个人 Key：已有时显示脱敏值 + 替换输入框；无时显示必填输入框，请求直连目标 Provider
- 新增 Provider 默认选择"组织 Key"
- **模型选择**：每个 Provider 卡片下方有 ModelSelect 组件（可搜索多选），点击展开下拉面板
  - 首次打开自动调用 `GET /llm/providers/{provider}/models` 拉取可用模型，带刷新按钮
  - 模型列表支持搜索过滤，展示 model ID + 名称 + context window
  - 已选模型以 tag 形式显示在输入框内，可逐个移除
  - 自定义 Provider（minimax-*）必须至少选一个模型，否则显示警告；内置 Provider 可选
  - 模型选择存储在 `user_llm_configs.selected_models` (JSONB)，写入 openclaw.json 的 models 数组
- "保存并重启"按钮在有未保存变更（dirty）时高亮
- 保存流程：upsert 个人 Key -> 保存 LLM 配置（含 selected_models）-> 同步 NFS -> 重启 OpenClaw
- NFS 不可用时显示专属错误状态（HardDrive 图标 + 错误信息），不显示配置编辑区

- 视图切换：基因 / 基因组 / 进化趋势
- 搜索栏 + 标签筛选（能力/性格/知识/工具）+ 领域分类（开发/数据/运维 等）
- 推荐区（横向卡片滚动）
- 卡片网格：图标、名称、摘要、标签、评分、效能分、安装数
- 排序：热门 / 评分 / 效能 / 最新
- 变体标记（"由 AgentX 进化"）和 Agent 原创标记
- 进化趋势 Tab：统计卡片（总数/学习数/失败数/Agent 创造数）、热门基因排行、活动流、待审核列表

## P14 基因详情页 `/gene-market/gene/:id`

- 头部：名称、图标、标签、版本、来源
- 描述（Markdown 渲染）

- 描述、包含的基因列表
- 评分区
- 应用按钮 -> 实例选择器 -> 预览已装/未装

## P16 实例基因 Tab `/instances/:id/genes`

- 已安装基因列表（状态、学习方式标记、效能分、版本）
- 学习中/失败状态指示 + 重试按钮
- 发布变体按钮（学习产物发布到市场）
- 创造基因按钮（触发 Agent 提炼经验）
- 卸载、升级
- 快捷入口：浏览市场、应用基因组

## P17 管理平台基因运营页 `/gene`（claw-buddy-frontend）

四个 Tab 页面：

### 概览
- 统计卡片：总基因数、总安装数、学习中、失败数、Agent 创造数
- 活动流时间线
- 待审核基因快览（通过/拒绝操作）

### 基因管理
- 搜索、分类筛选、发布状态筛选
- 表格列表：名称、slug、分类、来源、学习数、评分、发布状态
- 操作：创建、编辑（弹窗）、发布/下架、删除
- 分页

### 基因组管理
- 搜索、发布状态筛选
- 表格列表：名称、slug、包含基因、学习数、评分、发布状态
- 操作：创建、编辑（弹窗，含基因选择）、发布/下架、删除
- 分页

### 审核队列
- 待审核基因列表（名称、slug、来源、审核状态、创建时间）
- 操作：通过、拒绝

## 群聊中的基因推荐（无独立页面）

- Agent 加入工作区后，meta-learning 基因驱动其分析团队目标，在群聊中推荐基因
- 群聊消息中提到的基因 slug 自动渲染为可点击链接（跳转基因详情页）
- Agent 执行 Skill 相关回复后，消息末尾显示赞/踩按钮
- 用户也可在群聊中手动推荐基因给 Agent
