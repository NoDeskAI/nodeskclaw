# 前端 i18n（国际化）漏项审计清单

更新时间：2026-02-25

## 审计范围与方法

- 范围：
  - `claw-buddy-portal/src`
  - `claw-buddy-frontend/src`
- 方法：
  - 扫描 `vue/ts` 文件中的硬编码可见文案（标题、按钮、表单 label/placeholder、Toast/Alert/Confirm、空状态、状态文案）
  - 结合页面职责做优先级分层（高/中/低）
  - 非用户可见文本（纯日志、注释、类型名）不纳入统计

## message_key（文案键）命名建议

建议按「域.模块.语义」组织，统一小写点分：

- `auth.login.title`
- `auth.login.password_placeholder`
- `instance.list.empty`
- `instance.detail.restart_failed`
- `workspace.create.submit`
- `platform.users.add_staff`
- `cluster.detail.update_kubeconfig`
- `deploy.progress.timeout`

## 建议落地顺序

1. 高优先级：登录与主导航、实例/集群/部署主流程、平台管理主流程
2. 中优先级：Dashboard/Events/Settings/Gene
3. 低优先级：辅助组件与占位页面
