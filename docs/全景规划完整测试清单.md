## 测试执行方式

### 构建检查

```bash
cd nodeskclaw-portal
npm run build        # TypeScript 编译 + Vite 构建，确认无编译错误
vue-tsc -b           # 类型检查
```

### 手动测试核心链路

1. **过道系统完整流程**：进入工作区 -> 点击空白格子 -> 放置过道 -> 观察自动连接线出现 -> 再放一个 Agent -> 验证过道和 Agent 之间有连接 -> 在 2D 视图确认同样显示
2. **Human Hex 完整流程**：点击空白格子 -> 放置人类工位 -> 选择成员 -> 确认 Hex 出现且为暖色 -> 点击查看 Channel 配置 -> 弹出配置对话框 -> 切换 Webhook/WebSocket 模式 -> 填写 chat_id 保存
3. **黑板 v2 完整流程**：点击黑板 -> 6 个 Tab 逐个切换 -> 创建任务 -> 拖拽任务到 Doing -> 拖拽到 Done -> 查看绩效 -> 查看拓扑健康度
4. **基因市场**：搜索基因 -> 确认原生工具徽章显示 -> 查看基因组 -> 查看进化记录
5. **实例工具管理**：进入实例 -> 工具管理 -> 添加 MCP Server -> 启用/禁用 -> 删除；安装含 tool_allow 基因后验证 tools.allow 更新
