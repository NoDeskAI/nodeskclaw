## 三、测试执行说明

### 前端测试

```bash
cd claw-buddy-portal
npm run test        # Vitest 单元测试
npm run build       # 构建检查
```

对应测试代码：`claw-buddy-portal/tests/full-spec.test.ts`

### 后端测试

```bash
cd claw-buddy-backend
uv run pytest                    # 全量
uv run ruff check .              # lint 检查
```

### 手动验证流程（核心链路）

1. **过道系统**：创建工作区 → 放置 Agent → 放置过道 Hex → 观察自动连接 → 发送消息 → 验证路由规则
2. **Human Hex**：放置人类工位 → 配置飞书 Channel → 发送消息到 Human Hex → 飞书群收到 → 飞书回复 → 工作区收到
3. **黑板 v2**：打开黑板面板 → 6 个 Tab 切换 → 创建任务 → 拖拽到不同列 → 查看绩效排名
4. **审批流**：Agent 提交审批请求 → Human Hex 收到通知 → 飞书群收到卡片 → 审批 → 状态更新
5. **定时触发**：创建 schedule → 等待 cron 触发 → Agent 收到系统消息
6. **模板系统**：工作区配好后"保存为模板" → 新建工作区时"从模板创建"
